**Warung Senja — Twilight Wok Rush**: a timed Indonesian street-kitchen cooking game. Run the warung through the dinner rush: take orders from the board, grab ingredients off the counter, wok and grill them at the right moment, assemble each dish on a plate, and ring the bell before the customer's patience runs out. Combos, burnt food, a trash bin, and a 3-minute shift with a coin target.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Click stations to cook, or use keys 1–8 for ingredients, Space to serve, P to pause, M to mute. No network requests — everything is static files under `game/`, all art drawn in code and all sounds synthesized with WebAudio.
